# proyek_3--Immanoel
Perkembangan Pembelajaran

Pada tahap awal, saya mempelajari struktur dasar HTML menggunakan doctype, elemen html, head, body, heading, paragraf, gambar, link, header, nav, main, section, dan footer. Saya juga belajar menggunakan atribut seperti lang, viewport, id, class, dan alt.

Setelah memahami struktur dasar HTML, saya mulai menggunakan CSS untuk mengatur tampilan halaman. Saya mempelajari selector, warna, background, font, margin, padding, border, border-radius, serta konsep box-sizing. Saya kemudian mengenal CSS Custom Properties atau variables untuk menyimpan nilai warna dan spacing sehingga styling menjadi lebih mudah dikelola.

Tahap berikutnya adalah mempelajari layout menggunakan Flexbox. Saya menggunakan display: flex, flex-direction, justify-content, align-items, gap, dan flex-wrap untuk mengatur navigation, pricing cards, dan card profil. Saya juga mempelajari responsive design menggunakan media query dengan breakpoint 768px. Layout kemudian diuji pada ukuran layar berbeda agar tidak mengalami horizontal overflow.

Saya juga mempelajari pseudo-class seperti :hover dan :focus-visible. :hover digunakan untuk memberikan feedback ketika pointer berada di atas elemen, sedangkan :focus-visible membantu pengguna keyboard mengetahui elemen yang sedang mendapatkan fokus. Selain itu, saya belajar memperhatikan accessibility melalui penggunaan alt pada gambar, struktur heading, kontras warna, dan navigasi yang jelas.

Proyek

Beberapa eksperimen yang terdapat dalam repository ini meliputi:

Eksperimen HTML – memahami struktur dasar HTML dan elemen semantik.
Paket Lokakarya – menerapkan CSS, pricing card, Flexbox, hover, focus, dan responsive layout.
Profil Mahasiswa – menerapkan navigation, card layout, gambar, link email, dan responsive design.
Mini Project  – menerapkan hasil pembelajaran HTML dan CSS ke dalam landing page produk edukasi seni.
Refleksi

Hal yang paling membantu dalam proses pembelajaran adalah melakukan perubahan kode secara bertahap dan melihat hasilnya langsung melalui browser. Saya menjadi lebih memahami bahwa HTML berfungsi membangun struktur dan makna konten, sedangkan CSS digunakan untuk mengatur tampilan dan layout. Saya juga memahami bahwa penggunaan elemen semantik membuat struktur halaman lebih jelas dibandingkan hanya menggunakan <div> untuk semua bagian.

Kesulitan terbesar adalah memahami hubungan antara ukuran elemen, Flexbox, spacing, dan responsive layout. Beberapa perubahan CSS dapat membuat tampilan menjadi terlalu lebar atau tidak sesuai pada ukuran layar tertentu. Dari kesalahan tersebut saya belajar menggunakan max-width, flex-wrap, box-sizing, dan media query untuk membuat layout lebih fleksibel.

Saya menggunakan bantuan AI untuk memahami konsep dan mendapatkan saran, tetapi saya tetap melakukan eksperimen dan perubahan kode sendiri. Proses ini membantu saya memahami kode, bukan hanya mendapatkan hasil akhirnya. Ke depannya saya ingin memperkuat kemampuan CSS, terutama responsive design, Flexbox, accessibility, dan kemampuan membaca serta memperbaiki masalah layout melalui DevTools.
